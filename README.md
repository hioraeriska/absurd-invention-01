# The Hold-Music Showerhead

One-sentence absurd invention pitch for the [One-Sentence Absurd Invention Pitch](https://make.fun/c/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) competition on make.fun.

The pitch: a showerhead that pauses your shower and plays hold music whenever someone flushes the toilet, so you never get scalded mid-rinse.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the single-sentence pitch to `out/entry.txt`.
